# Logo options

`logo-options.html` is a standalone comparison page — open it directly in a
browser, no build step, no dependencies. It shows six hand-coded SVG
directions for the Beacon mark side by side on dark and light backgrounds,
plus at 32px to check legibility in the collapsed sidebar.

**Chosen: A, "Signal ping"** — now live at `app/static/images/beacon-icon.svg`
and `beacon-logo.svg`.

Kept here so any of the other five (lighthouse, alert bell, monogram badge,
shield + pulse, signal bars) can be revisited later without redoing the
design work — open the file, compare, done.
